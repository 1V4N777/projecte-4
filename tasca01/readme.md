# Tasca 1 – Creació d'un Kanban amb Microsoft Planner

## Objectiu
Crear un tauler Kanban compartit amb Microsoft Planner per organitzar, repartir i fer el seguiment de les tasques del projecte entre els dos membres del grup.

## Desenvolupament de l'activitat

1. Crear un pla bàsic a Microsoft Planner utilitzant la plantilla **Plan Simple**.
2. Compartir el pla amb el company de grup mitjançant un grup nou i configurar-lo com a públic.
3. Comprovar que tots dos membres poden accedir al tauler i afegir tasques.
4. Completar el **Backlog** amb totes les tasques que s'han de realitzar durant el projecte.
5. Assignar cada tasca a un membre del grup quan passi a l'estat **En procés**, indicant també una data de venciment.
6. Quan una tasca estigui acabada, moure-la a **Finalitzada** i registrar la data real de finalització.
7. Actualitzar diàriament l'estat de les tasques segons el progrés del projecte.

## Documentació i lliurament

Dins de la carpeta `Tasca1` del repositori, cal crear el document `Kanban.md`, que ha d'incloure:

- Relació inicial de totes les tasques del Backlog.
- Captures del tauler Kanban cada divendres, al final de cada setmana.
- Captura de l'estat final del projecte.
- Gràfics de resum generats per Microsoft Planner, cadascun en una captura individual.
