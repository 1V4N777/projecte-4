# Activitat – Gestors gràfics d'administració de Linux

## Objectiu
Instal·lar, configurar i provar diferents gestors gràfics d'administració de servidors Linux (Ubuntu Server) per comparar-ne les característiques i recomanar la millor solució a un client final.

## Fase 1 – Instal·lació individual

Cada membre de l'equip treballarà amb el seu propi servidor Ubuntu Server i instal·larà un gestor gràfic diferent:

- **Cockpit**
- **Webmin**
- **Ajenti** (només per a grups de tres membres).

### Desenvolupament

1. Instal·lar el gestor gràfic assignat mitjançant els repositoris o l'script oficial.
2. Accedir a la interfície web des del navegador del PC amfitrió, utilitzant l'adreça IP de la interfície `host-only` i el port corresponent.
3. Documentar les comandes utilitzades durant la instal·lació.
4. Explicar les incidències trobades i les solucions aplicades.
5. Afegir captures de pantalla de la instal·lació i del primer accés.
6. Explicar el funcionament i les principals funcionalitats del gestor.
7. Provar dues funcionalitats importants, com ara crear usuaris o grups i modificar contrasenyes, documentant el procés amb captures.

### Ports d'accés

| Gestor gràfic | Port |
|---|---|
| Cockpit | 9090 |
| Webmin | 10000 |
| Ajenti | 8000 |

## Fase 2 – Comparativa i exposició final

Els membres de l'equip compartiran les seves experiències amb els diferents gestors gràfics i elaboraran una presentació amb les conclusions i una recomanació per al client final.
